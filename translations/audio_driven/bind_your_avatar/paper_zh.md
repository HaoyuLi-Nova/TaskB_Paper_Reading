## 摘要

近年来音频驱动 talking head 生成取得了显著进展。然而，现有方法主要聚焦单角色场景。尽管某些方法能为两个人分别创建独立的对话视频，**在同一空间环境中生成多个物理共现角色的统一对话视频**这一关键挑战仍基本未被解决。该设定提出两项关键挑战：音频到角色的对应控制，以及缺少同一场景中多角色说话视频的合适数据集。为应对这些挑战，我们引入 **Bind-Your-Avatar**，一种专门为同一场景中多人说话角色视频生成设计的、基于 MM-DiT 的模型。具体而言，我们提出：（1）一种包含细粒度 **Embedding Router** 的新框架，将**「谁」**与**「说什么」**绑定在一起，以解决音频到角色的对应控制；（2）两种实现 3D 掩码 embedding router 的方法，以实现对个别角色的按帧细粒度控制，并基于所观察到的几何先验设计不同损失函数，以及一种掩码精炼策略，以提升预测掩码的精度与时间平滑性；（3）据我们所知，首个专门为多人说话角色视频生成构建的数据集，并配以开源数据处理管线；（4）面向双人说话角色视频生成的基准，大量实验表明相对多种先进方法具有更优性能。

## 1. 引言

通过多样控制信号（包括音频、面部关键点、文本提示与稠密运动流）从静态肖像生成可动画化的虚拟人，是计算机视觉与图形学中的基础挑战。该技术在游戏、电影制作与虚拟现实中有广泛应用。在这些控制信号驱动的动画技术中，音频驱动动画（通常称为 talking head 生成）尤为重要且被广泛研究。它聚焦合成逼真数字角色，使其面部表情、口型与头部姿态与输入语音精确同步。近期复杂方法在高保真说话肖像生成上取得显著进展，近期进展很大程度上由扩散模型驱动（EchoMimic、Hallo2、Hallo3、Sonic、OmniHuman-1、EMO2、EchoMimicV2、MegActor-$S$、MoCha、MagicInfinite、Let’s Talk、Teller、FantasyTalking、JoyGen 等），但仍主要受限于单角色场景。尽管某些方法能生成分别处于不同场景、彼此隔离的多人说话视频（ChatAnyone、INFP、Let’sGo 等），**生成多个物理共现、共享同一空间环境的统一多人说话视频**这一关键挑战仍基本未被解决。

本文推进对如下设定的研究：在同一场景中生成包含两个物理交互角色的统一多人说话视频，条件为多流语音输入、多张参考角色图像与自然语言描述。我们将这一新设定称为 **多人说话角色视频生成**（Multi-Talking-Character Video Generation）任务。不同于仅聚焦单角色的传统 talking-head 生成，该任务涉及多角色驱动条件，因而需要把每一路语音准确绑定到对应角色。此外，传统 talking-head 通常把参考角色图像用作生成视频的首帧（下文称该图像为**修复帧** inpainting frame）；这一做法不适用于多角色设定，因为我们不能简单拼接多张角色参考图来构成修复帧。取而代之，我们用自然语言描述来组合初始帧。如表 1 所总结，相对其他音频驱动多模态方法，本方法独特地支持对该新任务至关重要的更灵活输入模态。

该任务提出两项关键挑战：（1）精确控制音频到角色的对应，确保每个角色仅由其各自语音驱动；（2）缺少同一场景中多角色说话视频的合适数据集，阻碍了该设定下有效模型的推进。为应对这些挑战，我们引入 **Bind-Your-Avatar**，一种专门为同一场景中多人说话角色视频生成设计的、基于 MM-DiT 的模型。

![图 2](../../../arxiv/audio_driven/bind_your_avatar/extracted/figure1.png)

**图 2.** 所提框架概览，包含四个主要组件：（1）**多模态扩散 Transformer（MM-DiT）**，在文本、音频与视觉输入条件下生成视频序列；（2）**Face Encoder**，提取面部特征；（3）**Audio Encoder**，捕获与运动相关的信息；（4）**Embedding Router**，将「谁」与「说什么」绑定在一起，实现精确的音频到角色对应控制。MM-DiT 中的双路掩码引导交叉注意力模块，利用 embedding router 预测的细粒度掩码，有选择地把与运动相关的语音信息以及面部嵌入纳入视觉 token。

对挑战（1），我们设计基于 Diffusion Transformer 的新框架，其中包含细粒度 Embedding Router，在共享场景中把说话人身份（「谁」）与语音内容（「什么」）绑定。我们探索了三种实现该 router 的方式：**Pre-Denoise Router** 用修复帧上的人脸检测引导语音对齐，但在动态场景与近距离交互中失败；**Post-Denoise Router** 先生成无声视频以获得角色掩码，但引入昂贵的多遍计算；最优的 **Intra-Denoise Router** 在单次前向的去噪过程中动态生成视觉掩码，以极小开销达到相当精度。

对挑战（2），我们构建专门为多人说话角色视频生成设计的新数据集，包含从多样来源整理的超过 200 小时高质量视频。据我们所知，尚无专门为该任务构建的现有数据集。我们进一步开发自动化数据处理管线以支持该任务训练，执行三项核心操作：（a）从多角色重叠视频中分离各人语音；（b）为每个角色生成稠密分割掩码；（c）为每个音频片段与分割掩码分配角色身份标签，以指定其对应角色。

主要贡献如下：（1）我们首先引入多人说话角色视频生成任务，详细分析其挑战，并提出包含细粒度 embedding router 的新框架，将「谁」与「说什么」绑定，以解决同一场景中音频到角色的对应控制。（2）我们提出两种实现 3D 掩码 embedding router 的方法，以支持按帧细粒度控制。为进一步保证预测掩码的精度，我们引入基于几何的不同损失函数以及掩码精炼策略。（3）我们发布据我们所知**首个**专门为多人说话角色视频生成构建的数据集，并将开源数据清洗与处理管线以促进该领域后续研究。（4）我们建立双人说话角色视频生成任务的基准，并展示相对多种先进方法的更优性能。

## 2. 相关工作

### 2.1 音频驱动角色动画

早期音频驱动角色动画采用多阶段管线与中间表示，如关键点、深度图与神经场（Identity-Preserving Talking Face、X2Face、DA-GAN、AD-NeRF、MakeItTalk、Wav2Lip 等）。这些中间步骤通过显式建模结构简化了学习，但也引入误差累积并降低视觉真实感。近期扩散模型通过隐式学习几何、身份与运动使直接合成成为可能，从而去掉中间步骤并增强真实感（FantasyTalking、MoCha、MagicInfinite、Hallo3、EchoMimic、MegActor-$S$ 等）。尽管取得令人印象深刻的结果，这些方法依赖预定义修复帧——通常是用于引导生成的视频首帧——从而限制了场景灵活性。此外，它们主要聚焦单角色场景，限制了多角色应用，如表 1 所示。同期工作（MultiTalk、HunyuanVideo-Avatar）试图将 talking head 生成扩展到多角色场景，但仍依赖给定的修复帧。此外，它们使用静态掩码，限制了对动态场景的建模。

### 2.2 多概念视频生成

近期进展通过专门架构实现多概念视频生成。MAGREF 引入掩码引导用于多主体合成，DanceTogether 在交互场景中保持身份。Concat-ID 与 ConceptMaster 用拼接嵌入与解耦概念学习实现通用身份保持。Ingredients 将面部嵌入与视觉 token 投影到共享空间，计算相关性分数以把每个 token 分配给某个角色。然而，由于缺少自然约束 3D 掩码形状的几何先验，所得掩码精度不足且时间平滑性差。此外，这些方法主要依赖图像与文本条件，缺乏对音频驱动多角色生成的支持。这限制了它们在需要音频同步叙事内容创作场景中的适用性。

![图 3](../../../arxiv/audio_driven/bind_your_avatar/extracted/figure2.png)

**图 3.** 实现 **Embedding Router** 的三种方式示意：（1）**Pre-Denoise Router**，使用从修复帧提取的静态视觉掩码；（2）**Post-Denoise Router**，在初次去噪过程之后检测人脸区域；（3）**Intra-Denoise Router**，用可学习模块在去噪期间动态生成视觉掩码。

## 3. 方法

### 3.1 任务与问题形式化

给定如下输入：描述环境以及角色位置与动作的文本提示 $\mathbf{x}$；多路语音 $\mathbf{a}=\{\mathbf{a}_1,\mathbf{a}_2,\dots,\mathbf{a}_n\}$，其中 $n$ 为角色数，用于驱动每个角色的口型、面部表情与头部姿态；多张参考角色图像 $\mathbf{I}_r=\{\mathbf{i}_{r1},\mathbf{i}_{r2},\dots,\mathbf{i}_{rn}\}$，其中 $\mathbf{i}_{ri}\in\mathbb{R}^{3\times H\times W}$，用于保持角色面部特征；可选修复帧 $\mathbf{I}_i\in\mathbb{R}^{3\times H\times W}$；可选音频–角色矩阵 $\mathbf{A}^{\mathrm{ac}}\in\mathbb{R}^{n\times n}$，指示音频与角色之间的对应。目标是生成视频序列 $\mathbf{V}\in\mathbb{R}^{T\times 3\times H\times W}$，其中包含多个说话角色，每个角色的口型与头部姿态与其各自输入语音同步，身份则基于所给参考图准确保持。

### 3.2 框架

我们的框架主要建立在 CogVideoX 之上，这是一种多模态扩散 Transformer（MM-DiT）文本到视频基座模型。在时间步 $t$ 的训练过程中，我们先用预训练 3D VAE 编码器将视频序列 $\mathbf{V}$ 编码到潜空间 $\mathbf{z}_0\in\mathbb{R}^{T'\times C'\times H'\times W'}$，其中 $C'$ 为通道数，$T'$、$H'$、$W'$ 分别为潜空间的帧数、高与宽。类似地，我们将可选修复帧 $\mathbf{I}_i$ 以及拼接参考图 $\mathbf{I}_R$（在 RGB 空间中把多张参考角色图像 $\mathbf{I}_r$ 组合而成）编码到潜空间。这些潜表示再沿时间维填充，以匹配 $\mathbf{z}_0$ 的长度。最后，将这三路潜表示拼接，形成 $\mathbf{z}_0\in\mathbb{R}^{T'\times 3C'\times H'\times W'}$。

接下来，我们将潜表示 $\mathbf{z}_0$ 划分为 patch，得到视觉 token 序列 $\mathbf{v}\in\mathbb{R}^{S\times d}$，其中 $S$ 为序列长度，$d$ 为 Transformer 块的内部维。序列长度 $S$ 计算为 $S=T'\cdot H'/\tau\cdot W'/\tau$，其中 $\tau$ 表示 patch 大小。这些 token 与文本嵌入拼接，经过 $L$ 层扩散 Transformer 块以预测噪声 $\epsilon_\theta$，而 $\epsilon$ 是加到 $v$ 上的噪声，从标准正态分布采样（即 $\epsilon\sim\mathcal{N}(0,1)$）。最后计算扩散损失以优化模型：

$$
\mathcal{L}_{d}=\mathbb{E}_{v,t,\epsilon,x,I_r,a}\Bigl[\bigl\|\epsilon-\epsilon_\theta\bigl(v,t,\tau_\beta(x),\tau_\theta(I_r),\tau_\gamma(a)\bigr)\bigr\|_2^2\Bigr],
\tag{1}
$$

其中 $\tau_\beta(\cdot)$ 表示文本编码器，$\tau_\theta(\cdot)$ 表示人脸编码器，$\tau_\gamma(\cdot)$ 表示音频编码器。

**条件注入。** 如图 2 所示，为有效将条件注入去噪过程，我们用 T5 编码器编码文本条件。对音频条件，我们先用预训练 Wav2Vec 编码器提取音频特征，再投影到更高维空间。为解决音频特征与视觉特征之间的时间分辨率不对齐，我们用 2D 卷积对音频特征下采样，使其与视觉特征的时间分辨率对齐。所得音频表示记为音频嵌入 $\mathbf{e}_a$。为保持角色身份，我们沿用 ConsisID：用预训练 CLIP 提取全局特征，用预训练 InsightFace 提取局部面部特征，再用 Q-Former 融合得到精炼特征，记为角色面部嵌入 $\mathbf{e}_c$。接下来，我们通过 3D VAE 编码器对角色参考图与修复帧编码得到其潜表示。为更好利用各自信息量，编码前我们先对修复帧的面部区域加噪声，并从角色参考图中移除背景。最后，我们用掩码引导的交叉注意力有选择地将嵌入融入视觉 token，详见第 3.3 节。

### 3.3 Embedding Router

![图 4](../../../arxiv/audio_driven/bind_your_avatar/extracted/figure3.png)

**图 4.** 所提 Intra-Denoise Router 的架构。多角色面部与音频嵌入（左侧绿色与蓝色方块）利用预训练交叉注意力中丰富的跨模态表示，再经轻量 Transformer 捕获全局依赖并精炼掩码。所得细掩码与经矩阵乘法得到的音频–视觉矩阵，用于有选择地把嵌入注入对应角色。

为解决同一场景中音频到角色的对应控制，我们设计 embedding router，把说话人身份（「谁」）与语音内容（「什么」）绑定在一起。我们先给出 embedding router 的整体管线（图 3），突出所提基于 3D 掩码的方法，以处理动态场景与近距离角色交互。然后引入基于几何先验的弱监督损失函数，以引导准确的掩码预测。最后描述完整 embedding router 管线的网络架构与实现细节。

#### 3.3.1 整体管线

我们认为，用 embedding router 预测的时空掩码 $\mathbf{M}\in[0,1]^{n\times T'\times H'/\tau\times W'/\tau}$ 引导条件注入，是实现精确音频到角色对应控制的有效途径。这保证每个角色的面部与语音音频嵌入被准确路由到 DiT 块内各自的视觉 token。

我们首先尝试通过在修复帧 $\mathbf{I}_R$ 中检测人脸区域得到 2D 掩码，这是 talking-head 生成中的常见做法。该掩码随后被下采样并沿时间复制，以对齐视觉 token $\mathbf{v}$ 的维。然后我们用掩码引导的交叉注意力模块将嵌入注入 DiT 块，如图 3(a) 所示。我们称该方法为 **「Pre-Denoise Router」**，因为掩码在去噪过程之前预测。然而，该方法无法实现精确的音频到角色绑定：静态掩码无法适应角色位置跨帧变化的动态场景。此外，先验形状的边界框检测对两人靠近的情况不够细粒度，导致角色间混淆。

为弥补上述不足，我们提出基于 3D 掩码的 embedding router，并给出两种实现，见图 3(b)(c)。方法 (b) 称为 **Post-Denoise Router**（先粗生成再预测掩码），采用两阶段策略：先在无条件嵌入下去噪，生成粗略的无语音视频；再从生成帧预测细粒度 3D 掩码，用于后续精炼去噪。尽管该方法能实现更精确的音频到角色绑定，但由于推理时需要多次前向，计算开销显著。为进一步提升效率，我们引入 **Intra-Denoise Router**（去噪过程内动态预测）：训练一个 embedding router 模块，在去噪过程中动态预测细粒度 3D 掩码，消除多遍计算同时保持精度，见图 3(c)。

#### 3.3.2 Intra-Denoise Router 的损失函数

Intra-Denoise Router 基于高维面部嵌入与视觉 token 之间的相关性预测掩码，训练时使用交叉熵损失以及纳入几何先验的弱监督损失的组合。与 Ingredients 不同，我们将 router 模块的目标重写为多类分类任务，把背景当作额外一类（$n+1$）。该形式化减轻推理时背景区域噪声输出的影响。给定 Transformer 第 $l$ 层的视觉 token $\mathbf{v}$ 以及多张角色参考图 $\mathbf{I}_r$，router 模块预测 3D 视觉掩码 $\mathbf{M}$，指示每个视觉 token 对应哪个角色。router 模块主要用交叉熵损失优化：

$$
\mathcal{L}_r=\sum_{l,i,t,h,w=1}^{L,\,n,\,T',\,H'/\tau,\,W'/\tau}-y_{l,i,t,h,w}\log(\hat{y}_{l,i,t,h,w}),
\tag{2}
$$

其中 $y_{l,i,t,h,w}$ 表示角色 $i$ 在层 $l$、时间 $t$、高 $h$、宽 $w$ 处的真值掩码值，由预训练 SAM2 提取并下采样以匹配 $\mathbf{v}$ 的尺寸。router 模块的预测掩码值记为 $\hat{y}_{l,i,t,h,w}$。

相对 Ingredients 把每个视觉 token 当作孤立实体、难以产生平滑掩码，我们纳入**几何先验**，自然约束 3D 掩码形状以增强平滑性与一致性，并跟随三项约束：（1）时空一致性；（2）层间一致性；（3）身份互斥。鉴于几何先验，我们进一步设计若干弱监督损失以正则化 router 模块的训练：

$$
\mathcal{L}_{\mathrm{st}}=\sum_{l=1,\,i=1}^{L,\,n}\bigl\|\nabla_{\mathrm{Spatiotemporal}} M_{l,i,t}\bigr\|_1,
\tag{3}
$$

$$
\mathcal{L}_{\mathrm{layer}}=\sum_{i=1,\,t=1,\,h=1,\,w=1}^{n,\,T',\,H'/\tau,\,W'/\tau}\mathrm{Var}\bigl(\{M_{l,i,t,h,w}\}_{l=1}^{L}\bigr).
\tag{4}
$$

此处 $\nabla_{\mathrm{Spatiotemporal}} M_{l,i,t}$ 表示掩码 $M$ 的离散时空梯度，涵盖水平、竖直与时间轴上的变化。我们观察到损失项 $\mathcal{L}_r$ 本身已强制身份互斥，确保任一时空位置只预测一个角色。优化 router 模块的总体损失定义为 $\mathcal{L}_{\mathrm{router}}$：

$$
\mathcal{L}_{\mathrm{router}}=\mathcal{L}_r+\lambda_{st}\mathcal{L}_{st}+\lambda_l\mathcal{L}_{\mathrm{layer}},
\tag{5}
$$

其中 $\lambda_{st}$ 与 $\lambda_l$ 为损失权重。

#### 3.3.3 架构实现

如图 4 所示，我们的 router 模块架构同时整合几何先验与面部交叉注意力中丰富的跨模态表示，后者在第一阶段预训练（第 3.4 节）。网络结构细节见附录。

推理时，我们通过丢弃低置信预测并用半监督聚类保证时空一致性来精炼预测掩码。受 EMO 等工作启发，为给角色运动更多灵活性，我们通过对音频交叉注意力掩码取反并沿角色维交换来膨胀该掩码。

得到第 $l$ 层掩码 $M$ 后，可将其视为角色–视觉矩阵 $\mathbf{A}^{\mathrm{cv}}\in\mathbb{R}^{n\times s}$（其中 $s=T'\cdot H'/\tau\cdot W'/\tau$ 为视觉 token 序列长度），进而通过下式得到音频–视觉矩阵 $\mathbf{A}^{\mathrm{av}}$：

$$
\mathbf{A}^{\mathrm{av}}=\mathbf{A}^{\mathrm{ac}}\cdot\mathbf{A}^{\mathrm{cv}},
\tag{6}
$$

其中 $\mathbf{A}^{\mathrm{ac}}\in\mathbb{R}^{n\times n}$ 为音频–角色矩阵，指示音频与角色之间的对应。该矩阵既可作为输入条件提供，也可由我们所提音频 router 模块预测。本文中，我们用预训练语音–人脸对齐模型计算音频流与角色之间的相关性分数，再经投票机制得到最终音频–角色矩阵。最后，我们分两步顺序应用掩码引导交叉注意力，将面部嵌入以及与运动相关的语音信息融入视觉 token：

$$
\mathbf{v}'=\mathbf{v}+\mathbf{A}^{\mathrm{cv}}\cdot\texttt{FaceCrossAttn}(\mathbf{e}_c,\mathbf{v}),
\tag{7}
$$

$$
\mathbf{v}''=\mathbf{v}+\mathbf{A}^{\mathrm{av}}\cdot\texttt{AudioCrossAttn}(\mathbf{e}_a,\mathbf{v}'),
\tag{8}
$$

其中 $\mathbf{e}_c$ 与 $\mathbf{e}_a$ 分别表示角色面部嵌入与音频嵌入，如第 3.2 节所述。

### 3.4 多阶段训练

我们将训练分为连续三阶段，逐步增强模型能力：从身份保持，到音频驱动运动控制，再到多角色音频驱动动画。

**阶段 1：** 排除语音音频条件，聚焦身份保持以及从修复帧生成的能力。解冻 Transformer 与人脸嵌入提取器的全部参数。我们以 50% 概率随机丢弃修复帧，迫使模型在有条件与无条件场景下都能生成稳健输出。沿用 ConsisID，采用 50% 应用率的 Dynamic Mask Loss。

**阶段 2：** 加入音频条件，并在视频 DiT 架构中加入 LoRA 作为额外可训练模块。除音频编码器、音频交叉注意力、人脸编码器、人脸交叉注意力以及 DiT 的 LoRA 外，其余参数全部固定。对不同条件组合做随机丢弃，以加强无分类器引导生成。

**阶段 3：** 引入 embedding router 模块，并与整个去噪过程联合训练。除 embedding router 模块、音频交叉注意力、人脸交叉注意力以及 DiT 的 LoRA 外，其余参数全部固定。我们采用两任务混合训练范式，将训练分为单角色与多角色动画任务。这些任务使用不同训练数据，同时共享同一套网络参数。对单角色场景，我们将输入条件复制 $n$ 次，以匹配模型所期望的多角色输入格式。我们还采用 teacher-forcing 训练策略以稳定训练过程，详见附录。

## 4. 数据集

为应对同一场景中多人说话角色视频数据集缺失的挑战，我们引入新数据集 **MTCC**（Multi-Talking-Characters-Conversations），专门为多人说话角色视频生成设计。该数据集包含超过 200 小时原始视频素材，整理自脱口秀、访谈、新闻、在线课程与电视剧等多样来源，以确保角色、场景与交互的多样性。

### 4.1 数据清洗

我们施加一系列自动化数据清洗步骤以保证数据集质量——我们认为该阶段对训练至关重要。首先按分辨率、时长与 FPS 过滤原始视频。然后用人脸检测模型提取边界框，并分离恰好包含两个角色的片段。接下来计算边界框到角色间距之比，排除身体相距过远的片段。最后做口型同步质量过滤。直接对片段应用 Sync-C 会因两人重叠说话而产生噪声输出，因而同时对话的片段会被错误滤除。为克服这一点，我们用 AV\_MossFormer2\_TSE\_16K 模型分离语音轨并去除无关噪声。Sync-C 对每个角色的隔离音频与裁剪面部视频分别计算，这两个分数的平均作为过滤准则。

### 4.2 处理管线

为使能多角色视频训练，我们在数据清洗之后构建完整预处理管线。该管线包括片段提取、语音分离、音频嵌入提取与描述生成。具体而言，我们用 SAM2 获得按角色的分割掩码，下采样到潜空间，作为路由掩码的真值。用 AV\_MossFormer2\_TSE\_16K 从重叠视频中分离语音轨，建立编码音频与角色对应的音频–角色矩阵 $\mathbf{A}_{\mathrm{ac}}$。用 Wav2Vec 从每段隔离语音提取音频嵌入。最后用 QWEN2-VL 为所有片段生成描述性字幕。

## 5. 实验

### 5.1 Bind-Your-Avatar-Benchmark

据我们所知，尚无专门为多人说话角色场景设计的公开基准。为全面评估模型在多样真实场景中驱动任意角色的泛化能力，我们引入新基准 **Bind-Your-Avatar-Benchmark**。我们精心收集了 40 对来自不同领域的肖像，风格混杂，例如类提夫林的奇幻生物与科幻风格的人形机器人。这些肖像覆盖广泛年龄段，包括成人、青年、青少年与婴儿，背景从写实场景跨越到奇幻与科幻景观。每对肖像配有由文本到语音模型生成的对应双流语音片段，以及文本提示。这些提示描述不同外观（如戴墨镜、穿黑西装）、动作（如伸手、摇头）与环境（如窗外景色在变化）。基准包含两个子集：20 对带有对应修复帧，其余 20 对没有，从而为不同研究需求提供灵活性，预期将显著惠及社区发展。

#### 5.2.1 实现细节

为简化，所有实验中将角色数 $n$ 设为 2。三个训练阶段分别为 10,000、40,000 与 10,000 步。总 batch size 为 16，学习率为 $1\times 10^{-5}$。为增强无分类器引导，训练时参考图、修复帧与音频各以 0.05 的概率随机丢弃。$\mathcal{L}_r$、$\mathcal{L}_{st}$ 与 $\mathcal{L}_{\mathrm{layer}}$ 的损失权重分别设为 1、0.001 与 8。推理使用 50 步采样，音频与文本的无分类器引导（CFG）尺度均设为 7。训练集包括：（1）单角色数据集：Hallo3、HDTF、VFHQ；（2）多角色数据集：VICO、Friends-MMC 以及我们的数据集。VFHQ 因其无声特性用 URL 标签整理。对 VICO，我们将按角色的视频拼接成统一多角色场景。Friends-MMC 按与我们数据集相同的方式清洗与预处理。

#### 5.2.2 评测指标

我们从三方面评测所有方法：身份保持、音视频同步与视觉质量。

**身份保持：** 沿用 ConsisID、Ingredients，用 FaceNet 计算参考脸与生成脸之间的成对人脸相似度（Face Sim）。

**音视频同步：** 对每个角色，用人脸检测器裁剪脸部，并用 AV\_MossFormer2\_TSE\_16K 做语音分离。然后计算 Sync-C 与 Sync-D 分数（量化音视频同步质量的指标），再对所有角色取平均。

**视觉质量：** 用 FID（在面部区域上、基于 InceptionV3）与 FVD 评估生成质量。

#### 5.2.3 测试集

对多人说话角色视频生成任务，我们采用两个测试集。第一个包含从所提 MTCC 数据集得到的 20 个片段。第二个使用 Bind-Your-Avatar-Benchmark 中带修复帧的 20 对。对多人说话角色视频生成（无修复帧）任务，我们使用 Bind-Your-Avatar-Benchmark 中不带修复帧的 20 对。这些精心选择的测试集与基准一起，使我们能在不同视频生成任务上对本方法做充分而细致的评测。

## 6. 结论

本文提出 Bind-Your-Avatar，一种基于 MM-DiT、用于共享场景中多人说话角色视频生成的框架。为应对音频到角色对应的挑战，我们提出细粒度 embedding router，将「谁」与「说什么」绑定在一起。我们引入两种 3D 掩码 router 实现，配以基于几何的损失与掩码精炼。为支持该任务，我们构建首个专用数据集并发布开源数据处理管线。在 MTCC 与 Bind-Your-Avatar-Benchmark 上的大量实验证明了本方法的有效性。

### 6.1 局限

我们的模型缺少显式人体运动建模，且训练于有限的音频驱动视频数据，其中很少包含多人交互。这导致手势不够理想、角色交互不够真实。此外，MM-DiT 的全注意力架构带来高推理成本，限制了实时适用性。未来工作将聚焦提升运动保真度并降低计算开销，以便实际部署。

## 附录 A. Intra-Denoise Router 架构

Intra-Denoise Router 的网络架构以第 3.3 节所述几何先验为基础，利用预训练面部交叉注意力所捕获的丰富跨模态表示。具体如图 4 所示，我们将预训练多头人脸交叉注意力模块的查询与键输出作为 router 模块的输入。查询与键均经逐层线性变换，再做保持头维的 reshape。经变换后的查询与键做矩阵乘法得到的注意力权重，编码面部特征与视觉 token 之间的对应。这些权重在进入多个建模视觉 token 相互依赖的时空注意力层之前，用 3D RoPE 位置编码增强。最后一层线性层加 softmax 激活生成预测掩码输出。该设计整体捕获孤立的特征–token 对应以及时空 token 依赖，二者对产生精确、平滑的掩码都必不可少。

## 附录 B. Teacher-Forcing 训练策略

我们观察到，将 router 模块与整个去噪过程联合训练常常导致平凡解：视觉 token 变得容易分类，但缺少有意义的视觉表示。同时，router 的训练依赖于模型已充分适配数据分布、能够高质量去噪。若没有准确的 router 预测，扩散模型会逐渐失去有效整合与利用所给条件的能力。

因此，我们采用 teacher-forcing 训练策略：强制 Transformer 扩散模型中掩码引导交叉注意力的输入为真值掩码值，并将 router 模块的计算图从去噪过程中分离。为增强噪声鲁棒性，我们对强制掩码值施加 dropout 并加入高斯噪声，有效起到数据增强的作用。
