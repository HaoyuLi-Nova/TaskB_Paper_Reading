## 摘要

本文表明，掩码自编码器（MAE）是用于计算机视觉的可扩展自监督学习器。我们的 MAE 方法很简单：对输入图像的随机图块（patch）进行掩码，然后重建缺失的像素。该方法基于两个核心设计。第一，我们设计了一种**非对称**编码器-解码器架构：编码器只作用于可见图块子集（不含掩码标记），配合一个轻量级解码器，该解码器从潜在表示和掩码标记中重建原始图像。第二，我们发现对输入图像进行高比例掩码（例如 75%）可以产生一个非平凡且有意义的自监督任务。这两种设计的结合使我们能够高效且有效地训练大型模型：训练速度加快（3 倍或以上）且精度提升。我们的可扩展方法允许学习具有良好泛化性的大容量模型：例如，一个原始的 ViT-Huge 模型在仅使用 ImageNet-1K 数据的方法中取得了最佳精度（87.8%）。在下游任务中的迁移性能优于有监督预训练，并展现出良好的扩展行为。

## 1. 引言

深度学习见证了能力与容量持续增长的架构爆炸式发展。借助硬件的快速进步，如今的模型可以轻松过拟合百万张图像，并开始需要数亿张——通常无法公开获取的——**有标签**图像。

这种对数据的渴求在自然语言处理（NLP）中已通过自监督预训练得到成功解决。基于 GPT 中的自回归语言建模和 BERT 中的**掩码自编码**的方法在概念上很简单：移除部分数据，然后学习预测被移除的内容。这些方法现已能够训练包含超过一千亿参数的通用 NLP 模型。

掩码自编码器的思想（作为更一般的去噪自编码器的一种形式）在计算机视觉中同样自然且适用。事实上，视觉领域的密切相关研究早于 BERT。然而，尽管在 BERT 成功之后人们对这一想法表现出极大兴趣，自编码方法在视觉中的进展仍落后于 NLP。我们追问：**是什么使得掩码自编码在视觉和语言之间有所不同？** 我们尝试从以下几个角度回答这个问题：

![图1：我们的 MAE 架构。预训练期间，随机遮掩大量图像图块（如 75%），编码器只作用于**可见图块**子集，掩码标记在编码器之后引入，完整的编码图块集合与掩码标记由一个小型解码器处理，以像素空间重建原始图像。预训练后，解码器被丢弃，编码器用于处理完整图像以完成识别任务。](../../../arxiv/foundations/mae/extracted/fig/arch.png)

**(i)** 直到最近，架构仍然不同。在视觉领域，卷积网络在过去十年占主导地位。卷积通常作用于规则网格，将"指示符"（如掩码标记或位置嵌入）集成到卷积网络中并不直接。然而，随着视觉 Transformer（ViT）的引入，这一架构差距已得到弥补，不再是障碍。

**(ii)** 语言和视觉的信息密度不同。语言是人类生成的高度语义化和信息密集的信号。当训练一个模型预测句子中仅有几个缺失的词时，这项任务似乎能诱导出复杂的语言理解。相比之下，图像是具有大量空间冗余的自然信号——例如，缺失的图块可以从邻近图块中以很少的对部件、对象和场景的高层理解恢复。为了克服这种差异并鼓励学习有用的特征，我们展示了一种在计算机视觉中有效的简单策略：遮掩**非常高比例**的随机图块。这种策略大大减少了冗余，创建了一项需要超越低层图像统计的整体理解的具有挑战性的自监督任务。

**(iii)** 自编码器的**解码器**（将潜在表示映射回输入）在重建文本和图像时扮演不同的角色。在视觉中，解码器重建**像素**，因此其输出的语义层次低于常见识别任务。这与语言形成对比，在语言中解码器预测包含丰富语义信息的缺失**词语**。虽然在 BERT 中解码器可以是平凡的（一个 MLP），但我们发现，对于图像，解码器设计在决定学到的潜在表示的语义层次上起着关键作用。

在这一分析的驱动下，我们提出了一种简单、有效且可扩展的用于视觉表示学习的掩码自编码器（MAE）。我们的 MAE 从输入图像中遮掩随机图块，并在像素空间重建缺失图块。它具有**非对称**的编码器-解码器设计：编码器只作用于可见图块子集（不含掩码标记），解码器是轻量级的，从潜在表示和掩码标记中重建输入（图 1）。将掩码标记移入小型解码器的这一非对称编码器-解码器设计大幅减少了计算量。在此设计下，非常高的遮掩比例（如 75%）可以实现双赢：在优化精度的同时，只需让编码器处理一小部分（如 25%）的图块。这可以将整体预训练时间减少 3 倍或以上，同时降低内存消耗，使我们能够轻松将 MAE 扩展到大型模型。

我们的 MAE 学习了具有良好泛化性的超大容量模型。通过 MAE 预训练，我们可以在 ImageNet-1K 上训练 ViT-Large/Huge 等数据饥渴型模型，并提升泛化性能。使用原始 ViT-Huge 模型，在 ImageNet-1K 上微调时达到 87.8% 的精度，优于仅使用 ImageNet-1K 数据的所有先前结果。我们还评估了目标检测、实例分割和语义分割上的迁移学习，这些任务中我们的预训练取得了优于有监督预训练的结果，更重要的是，我们观察到通过扩大模型规模可获得显著收益。这些观察与 NLP 自监督预训练中的发现一致，我们希望它们能推动我们的领域探索类似的发展轨迹。

## 2. 相关工作

**掩码语言建模**及其自回归对应方法（如 BERT 和 GPT）是 NLP 中非常成功的预训练方法。这些方法保留部分输入序列，训练模型预测缺失内容。这些方法已被证明具有出色的可扩展性，大量证据表明这些预训练表示能很好地泛化到各种下游任务。

**自编码**是学习表示的经典方法。它有一个将输入映射到潜在表示的编码器，和一个从潜在表示重建输入的解码器。例如，PCA 和 k-means 都是自编码器。去噪自编码器（DAE）是一类自编码器，它对输入信号进行破坏并学习重建原始未破坏信号。一系列方法可以被看作是在不同破坏方式下的广义 DAE，例如遮掩像素或去除颜色通道。我们的 MAE 是去噪自编码的一种形式，但在许多方面与经典 DAE 不同。

**掩码图像编码**方法从被遮掩破坏的图像中学习表示。Vincent 等人的开创性工作将掩码作为 DAE 中的一种噪声类型。Context Encoder 使用卷积网络填充大块缺失区域。受 NLP 成功的启发，相关近期方法基于 Transformer。iGPT 对像素序列进行操作并预测未知像素。ViT 论文研究用于自监督学习的掩码图块预测。最近，BEiT 提出预测离散标记。

**自监督学习**方法在计算机视觉中引发了重大兴趣，通常侧重于预训练的不同借口任务。近年来，对比学习很流行，它对两个或多个视图之间的图像相似性和差异性（或仅相似性）建模。对比学习及相关方法强烈依赖数据增强。自编码追求概念上不同的方向，展现出我们将要呈现的不同行为。

## 3. 方法

我们的掩码自编码器（MAE）是一种简单的自编码方法，给定部分观测即可重建原始信号。与所有自编码器一样，我们的方法有一个编码器将观测信号映射到潜在表示，以及一个从潜在表示重建原始信号的解码器。与经典自编码器不同，我们采用**非对称**设计：编码器只作用于部分观测信号（不含掩码标记），轻量级解码器从潜在表示和掩码标记中重建完整信号。图 1 展示了这一思想，下面逐一介绍。

**掩码。** 遵循 ViT，我们将图像分割为规则的非重叠图块。然后对图块子集进行采样，并遮掩（即移除）其余图块。我们的采样策略很直接：无放回地对图块进行随机采样，遵循均匀分布，我们简称此为"随机采样"。

高**遮掩比例**（即被移除图块的比例）的随机采样大大消除了冗余，从而创建一项无法简单通过从可见邻近图块外推来轻松解决的任务（见图 2–图 4）。均匀分布防止了潜在的中心偏差（即图像中心附近被遮掩图块更多）。最后，高度稀疏的输入为设计高效编码器创造了机会，下面介绍。

**MAE 编码器。** 我们的编码器是一个 ViT，但只作用于**可见的、未被遮掩的图块**。与标准 ViT 一样，我们的编码器通过线性投影加位置嵌入对图块进行嵌入，然后通过一系列 Transformer 块处理结果集合。然而，我们的编码器只处理全部图块集合的一小部分（如 25%）。被遮掩的图块被移除；不使用掩码标记。这使我们能够以极小的计算和内存训练非常大的编码器。完整集合由下面描述的轻量级解码器处理。

**MAE 解码器。** MAE 解码器的输入是由以下两部分组成的完整标记集合：(i) 编码后的可见图块，以及 (ii) 掩码标记。见图 1。每个掩码标记是一个共享的、可学习的向量，表示待预测的缺失图块的存在。我们为这个完整集合中的所有标记添加位置嵌入；若不这样做，掩码标记将没有关于其在图像中位置的信息。解码器由另一系列 Transformer 块组成。

MAE 解码器只在预训练期间用于执行图像重建任务（只有编码器用于为识别任务生成图像表示）。因此，解码器架构可以灵活设计，与编码器设计**独立**。我们使用比编码器更窄、更浅的非常小的解码器进行实验。例如，我们的默认解码器相比编码器每个标记的计算量不到 10%。在这种非对称设计下，完整标记集合只由轻量级解码器处理，从而大幅减少预训练时间。

**重建目标。** 我们的 MAE 通过预测每个被遮掩图块的**像素值**来重建输入。解码器输出中的每个元素是表示一个图块的像素值向量。解码器的最后一层是线性投影，其输出通道数等于图块中的像素值数量。解码器的输出被重塑以形成重建图像。我们的损失函数在像素空间中计算重建图像与原始图像之间的均方误差（MSE）。我们只在被遮掩的图块上计算损失，与 BERT 类似。$^1$

> $^1$ 只在被遮掩图块上计算损失与传统去噪自编码器（在所有像素上计算损失）不同。这一选择纯粹由结果驱动：在所有像素上计算损失会导致精度略有下降（约 0.5%）。

我们还研究了一种重建目标为每个被遮掩图块归一化像素值的变体。具体地，我们计算图块中所有像素的均值和标准差，并用它们归一化该图块。在我们的实验中，使用归一化像素作为重建目标可以提高表示质量。

**简单实现。** 我们的 MAE 预训练可以高效实现，且重要的是不需要任何专门的稀疏操作。首先，我们为每个输入图块生成一个标记（通过线性投影加位置嵌入）。接下来，**随机打乱**标记列表，并根据遮掩比例**移除**列表的最后一部分。此过程为编码器产生一小部分标记，等价于无放回地对图块采样。编码后，我们将掩码标记列表附加到编码图块列表后，然后**取消打乱**整个完整列表（逆转随机打乱操作）以将所有标记与其目标对齐。解码器作用于这个完整列表（加入位置嵌入）。如所述，不需要稀疏操作。这种简单实现引入的额外开销可忽略不计，因为打乱和取消打乱操作很快。

## 4. ImageNet 实验

我们在 ImageNet-1K（IN1K）训练集上进行自监督预训练，然后通过 (i) 端到端微调或 (ii) 线性探测进行有监督训练评估表示。我们报告单张 224×224 裁剪的 top-1 验证精度。详细信息见附录 A.1。

**基线：ViT-Large。** 我们在消融研究中使用 ViT-Large（ViT-L/16）作为主干。ViT-L 非常大（比 ResNet-50 大一个数量级），容易过拟合。以下是从头训练 ViT-L 与从我们基线 MAE 微调的对比：

| 从头训练（原始文献） | 从头训练（我们的实现） | 基线 MAE |
|:---:|:---:|:---:|
| 76.5 | 82.5 | 84.9 |

我们注意到，从头**有监督**训练 ViT-L 并不简单，需要包含强正则化的良好方案（82.5%，见附录 A.2）。即便如此，我们的 MAE 预训练贡献了很大的提升。这里微调只需 50 个 epoch（与从头训练的 200 个相比），意味着微调精度在很大程度上依赖于预训练。

### 4.1 主要特性

我们使用表 1 中的默认设置对 MAE 进行消融（见标题）。观察到几个有趣的特性。

**遮掩比例。** 图 5 展示了遮掩比例的影响。最优比例出人意料地高。75% 的比例对线性探测和微调都很好。这种行为与 BERT 形成对比，BERT 的典型遮掩比例为 15%。我们的遮掩比例也远高于计算机视觉相关工作中的比例（20%–50%）。

模型**推断**缺失图块，产生不同但合理的输出（图 4）。它理解对象和场景的整体感，无法简单通过延伸线条或纹理来完成。我们假设这种类推理行为与有用表示的学习有关。

**解码器设计。** 我们的 MAE 解码器可以灵活设计，如表 1(a)(b) 所研究。

表 1(a) 变化解码器深度（Transformer 块数）。对于线性探测，足够深的解码器很重要。这可以用像素重建任务和识别任务之间的差距来解释：自编码器中最后几层更专门用于重建，与识别关联性较少。足够深的解码器可以承担重建专业化，使潜在表示保持在更抽象的层次。这种设计在线性探测上可带来高达 8% 的提升（表 1(a)，"lin" 列）。但是，如果使用微调，编码器的最后几层可以被调整以适应识别任务，解码器深度对改善微调影响较小（表 1(a)，"ft" 列）。

有趣的是，使用**单块**解码器的 MAE 在微调时也表现出色（84.8%）。注意，单个 Transformer 块是将信息从可见标记传播到掩码标记的最低要求。如此小的解码器可以进一步加速训练。

在表 1(b) 中我们研究解码器宽度（通道数）。默认使用 512-d，在微调和线性探测下均表现良好。更窄的解码器在微调时也表现良好。

总体而言，我们的默认 MAE 解码器是轻量级的，具有 8 个块和 512-d 宽度（表 1 中灰色标注）。每个标记的 FLOPs 仅为 ViT-L（24 块，1024-d）的 9%。因此，尽管解码器处理所有标记，它仍只占整体计算的一小部分。

**掩码标记。** 我们 MAE 的一个重要设计是在编码器中跳过掩码标记 `[M]`，在轻量级解码器中再引入它。表 1(c) 研究了这一设计。

如果编码器**使用**掩码标记，性能更**差**：线性探测精度下降 14%。在这种情况下，预训练和部署之间存在差距：这个编码器在预训练时输入中有大量掩码标记，而在未破坏图像中不存在这些标记。这种差距可能在部署时降低精度。通过从编码器中移除掩码标记，我们约束编码器总是看到**真实**图块，从而提高精度。

此外，通过在编码器中跳过掩码标记，我们大幅减少了训练计算量。在表 1(c) 中，我们将整体训练 FLOPs 减少了 3.3 倍。这在我们的实现中带来 2.8 倍的挂钟加速（见表 2）。对于更小的解码器（1 块）、更大的编码器（ViT-H）或两者兼有，挂钟加速更大（3.5–4.1 倍）。注意，75% 遮掩比例时加速可以 >4 倍，部分原因是自注意力的复杂度是二次方的。此外，内存大幅减少，可以训练更大模型或通过大批次训练进一步加速。时间和内存效率使我们的 MAE 有利于训练非常大的模型。

**重建目标。** 我们在表 1(d) 中比较了不同的重建目标。我们迄今的结果基于无（逐图块）归一化的像素。使用**有**归一化的像素可以提高精度。这种逐图块归一化在局部增强了对比度。在另一个变体中，我们在图块空间中进行 PCA 并使用最大的 PCA 系数（此处为 96 个）作为目标，这样做会降低精度。两个实验都表明高频成分在我们的方法中是有用的。

我们还比较了预测**标记**的 MAE 变体，即 BEiT 中使用的目标。具体而言，我们使用 DALLE 预训练的 dVAE 作为分词器（遵循 BEiT）。这里 MAE 解码器用交叉熵损失预测标记索引。与未归一化像素相比，这种分词化将微调精度提高了 0.4%，但与归一化像素相比没有优势。它还降低了线性探测精度。在第 5 节中我们进一步展示分词化在迁移学习中并非必要。

我们**基于像素**的 MAE 比分词化简单得多。dVAE 分词器需要额外的预训练阶段，可能依赖额外数据（2.5 亿张图像）。dVAE 编码器是一个大型卷积网络（ViT-L 的 40% FLOPs），增加了不可忽视的开销。使用像素则没有这些问题。

**数据增强。** 表 1(e) 研究数据增强对我们 MAE 预训练的影响。

我们的 MAE 使用**仅裁剪**增强效果很好，无论固定尺寸还是随机尺寸（均有随机水平翻转）。添加颜色抖动会降低结果，因此我们在其他实验中不使用它。

令人惊讶的是，即使使用**无数据增强**（仅中心裁剪，不翻转），我们的 MAE 也表现得相当好。这一特性与对比学习及相关方法有显著不同，后者强烈依赖数据增强。已有观察指出，仅使用裁剪增强使 BYOL 精度降低 13%，SimCLR 降低 28%。此外，没有证据表明对比学习可以在没有增强的情况下工作：图像的两个视图相同，很容易满足平凡解。

在 MAE 中，数据增强的角色主要由随机掩码承担（下面消融）。每次迭代的掩码都不同，因此无论数据增强如何都会生成新的训练样本。借口任务由掩码使其变难，需要较少的增强来正则化训练。

**掩码采样策略。** 在表 1(f) 中我们比较了不同的掩码采样策略，如图 6 所示。

**块状**掩码策略（BEiT 中提出）倾向于移除大块（图 6 中间）。我们使用块状掩码的 MAE 在比例为 50% 时表现合理，但在 75% 时退化。这项任务比随机采样更难，观察到更高的训练损失，重建也更模糊。

我们还研究了**网格状**采样，它规律地保留每 4 个图块中的一个（图 6 右）。这是一项更容易的任务，训练损失更低，重建更清晰。但是，表示质量更低。

简单的随机采样对我们的 MAE 效果最佳。它允许更高的遮掩比例，在享受良好精度的同时带来更大的加速收益。

### 4.3 部分微调

表 1 显示线性探测和微调结果在很大程度上**不相关**。线性探测在过去几年是流行的协议，但它错过了追求**强但非线性**特征的机会——这实际上是深度学习的优势。作为折中，我们研究**部分微调**协议：微调最后几层，同时冻结其他层。这一协议也在早期工作中使用过。

图 9 展示了结果。值得注意的是，只微调**一个** Transformer 块就能显著将精度从 73.5% 提升到 81.0%。此外，如果只微调"半个"最后块（即其 MLP 子块），可以达到 79.1%，远好于线性探测。这个变体本质上是微调一个 MLP 头。微调少数几个块（如 4 或 6 个）可以达到接近完整微调的精度。

在图 9 中，我们还与 MoCo v3（一种有 ViT-L 结果可用的对比方法）进行比较。MoCo v3 线性探测精度更高，但其所有部分微调结果都差于 MAE。微调 4 个块时差距为 2.6%。虽然 MAE 表示的线性可分性较低，但它们是更强的**非线性**特征，在非线性头被调整时表现良好。

这些观察表明，线性可分性不是评估表示质量的唯一指标。也有研究（如 SimCLR）观察到，线性探测与迁移学习性能（如目标检测）的相关性不好。据我们所知，NLP 中线性评估并不常用于基准预训练。

![图9：部分微调结果，ViT-L，关于微调 Transformer 块数，使用表1中的默认设置。微调 0 个块为线性探测；微调 24 个块为完整微调。我们的 MAE 表示线性可分性较低，但只要微调一个或更多块，就始终优于 MoCo v3。](../../../arxiv/foundations/mae/extracted/fig/partial_ft.png)

## 6. 讨论与结论

能够良好扩展的简单算法是深度学习的核心。在 NLP 中，简单的自监督学习方法（如 GPT、BERT）使模型能够从指数级扩展中受益。在计算机视觉中，尽管自监督学习取得了进展，实用的预训练范式仍以有监督为主。在本研究中，我们在 ImageNet 和迁移学习上观察到，自编码器——一种类似于 NLP 技术的简单自监督方法——提供了可扩展的收益。视觉中的自监督学习现在可能正在踏上与 NLP 中类似的发展轨迹。

另一方面，我们注意到图像和语言是**本质不同的信号**，这种差异必须谨慎对待。图像仅仅是被记录的光，**没有**被分解为视觉类比于词语的语义单元。我们并非试图移除对象，而是移除最可能**不构成**语义片段的随机图块。同样，我们的 MAE 重建像素，这**不是**语义实体。尽管如此，我们观察到（如图 4 所示）我们的 MAE 推断出复杂的整体重建，表明它已学习了许多视觉概念，即语义。我们假设这种行为通过 MAE 内部丰富的隐藏表示发生。我们希望这一视角能启发未来的工作。

**更广泛的影响。** 所提方法基于训练数据集的学习统计信息预测内容，因此会反映这些数据中的偏差，包括具有负面社会影响的偏差。该模型可能生成不存在的内容。在基于本工作生成图像时，这些问题值得进一步研究和考虑。

### A.1 ImageNet 实验

**ViT 架构。** 我们遵循标准 ViT 架构。它有一堆 Transformer 块，每个块由多头自注意力块和 MLP 块组成，均含 LayerNorm（LN）。编码器以 LN 结束。由于 MAE 编码器和解码器宽度不同，我们在编码器之后采用线性投影层来匹配维度。我们的 MAE 为编码器和解码器输入都添加了位置嵌入（正弦-余弦版本）。我们的 MAE **不**使用相对位置或层缩放（BEiT 的代码中使用了这些）。

我们从编码器输出提取特征用于微调和线性探测。由于 ViT 有类标记，为了适应这一设计，在我们的 MAE 预训练中，我们将一个辅助虚拟标记附加到编码器输入。该标记在线性探测和微调中将被用作分类器训练的类标记。我们的 MAE 在没有这个标记时也同样工作良好（使用平均池化）。

**预训练。** 默认设置见表 8。我们**不**使用颜色抖动、drop path 或梯度裁剪。遵循 ViT 的官方代码，我们使用 xavier_uniform 初始化所有 Transformer 块。使用线性学习率缩放规则：$\text{lr} = \text{base\_lr} \times \text{batchsize} / 256$。

| 基础学习率 | 1.5e-4 |
| 权重衰减 | 0.05 |
| 优化器动量 | $\beta_1, \beta_2 = 0.9, 0.95$ |
| 批次大小 | 4096 |
| 学习率 schedule | 余弦衰减 |
| 预热 epoch | 40 |
| 数据增强 | RandomResizedCrop |

**端到端微调。** 我们的微调遵循有监督 ViT 训练的常见实践。默认设置见表 9。我们使用逐层学习率衰减（遵循 BEiT）。

**线性探测。** 我们的线性分类器训练遵循 MoCo v3。见表 10。我们观察到线性探测需要与端到端微调非常不同的方案。特别地，正则化通常对线性探测有害。遵循 MoCo v3，我们禁用了许多常见的正则化策略：不使用 mixup、cutmix、drop path 或颜色抖动，权重衰减设为零。

训练经典线性分类器（如 SVM）时，对分类器输入进行归一化是常见做法。类似地，训练线性探测分类器时，对预训练特征进行归一化是有益的。遵循 Doersch 等人，我们采用一个额外的 BatchNorm 层（不含仿射变换，`affine=False`）。该层应用于编码器产生的预训练特征，位于线性分类器之前。我们注意到该层**不**破坏线性性质，训练后可以被吸收进线性分类器：它本质上是一个重参数化的线性分类器。$^3$ 引入这一层有助于在我们的消融中校准不同变体的特征幅度，使它们无需进一步学习率搜索即可使用相同的设置。

> $^3$ 另一种方式是预先计算特征的均值和标准差，使用归一化特征训练线性分类器。

### A.2 从头监督训练 ViT-L/H

我们发现，在 ImageNet-1K 上从头**有监督**训练 ViT-L/H 并不简单。训练不稳定。虽然已有针对较小模型的强基线和公开实现（如 DeiT），但 ViT-L/H 的方案尚未被探索。直接将先前方案应用于这些较大模型行不通，训练期间经常出现 NaN 损失。

我们的方案见表 11。我们使用 0.3 的权重衰减、4096 的大批次和长预热，遵循原始 ViT。使用 $\beta_2 = 0.95$（遵循 iGPT）。我们使用表 11 中列出的正则化并禁用其他，遵循 Xiao 等人。所有这些选择都是为了提高训练稳定性。我们的方案可以完成训练而不出现 NaN 损失。ViT-L 精度为 82.6%（不含 EMA 为 81.5%），ViT-H 精度为 83.1%（不含 EMA 为 80.9%）。如果不使用 EMA，ViT-L 和 ViT-H 都显示出过拟合趋势。

作为副产品，我们对 ViT-B 的方案达到 82.3%（不含 EMA 为 82.1%），而 DeiT 为 81.8%。

**表11：从头监督训练 ViT 设置。**

|:---|:---|
| 优化器 | AdamW |
| 基础学习率 | 1e-4 |
| 权重衰减 | 0.3 |
| 优化器动量 | $\beta_1, \beta_2 = 0.9, 0.95$ |
| 批次大小 | 4096 |
| 学习率 schedule | 余弦衰减 |
| 预热 epoch | 20 |
| 训练 epoch | 300（B），200（L/H） |
| 数据增强 | RandAug (9, 0.5) |
| 标签平滑 | 0.1 |
| mixup | 0.8 |
| cutmix | 1.0 |
| drop path | 0.1（B），0.2（L/H） |
| 指数移动平均（EMA） | 0.9999 |

### A.3 COCO 目标检测与分割

我们将原始 ViT 调整用于 Mask R-CNN 中的 FPN 主干。ViT 有一堆 Transformer 块，所有块都在单一尺度（如步幅 16）产生特征图。我们将这堆块平均分为 4 个子集，并应用卷积对中间特征图进行上采样或下采样，以产生不同尺度（步幅 4、8、16 或 32，与标准 ResNet 相同）。FPN 建立在这些多尺度图上。

为了在不同方法之间进行公平比较，我们为表 4 中的每个条目（包括所有竞争者）搜索超参数。我们搜索的超参数为学习率、权重衰减、drop path 率和微调 epoch。我们将发布代码及具体配置。完整的模型和训练详情以及额外实验，见 Li 等人 (ViTDet)。

### A.4 ADE20K 语义分割

我们使用 UperNet，遵循 BEiT 的语义分割代码。我们以批次大小 16 端到端微调 100 epoch。我们为表 5 中的每个条目（包括所有竞争者）搜索最优学习率。

BEiT 的语义分割代码使用相对位置偏置。我们的 MAE 预训练**不**使用它。为了公平比较，我们**只在**迁移学习期间启用相对位置偏置，初始化为零。我们注意到我们的 BEiT 复现在预训练和微调中都使用相对位置偏置，遵循他们的代码。
