## 0. 先钉死时钟

Wan 3D VAE：空间 `/8`，时间「首帧不压、后面每 $4$ 像素帧压成 $1$ 格。DiT `patch_size=(1,2,2)`。

| 量                   | 像素域            | VAE 潜空间               | DiT patch 后                          |
| -------------------- | ----------------- | ------------------------ | ------------------------------------- |
| 时间                 | $T=81$ 帧       | $n_t=1+(81-1)/4=21$ 格 | 仍$21$（时间核是 $1$）            |
| 高×宽               | $480\times 832$ | $60\times 104$         | $30\times 52$（空间 $2\times 2$） |
| 视频 token 数$L_v$ | —                | —                       | $21\times 30\times 52=32760$        |

论文图 3(a) 的 $F+1$ 就是这 $21$ 个**时间格**（空间被压成一排粉格子）；$4F+1=81$ 是按 $24$ fps 对齐后的**音频帧数**。图里一颗粉格，真实对应 $30\times 52=1560$ 个空间 token，它们**共用**同一行时间掩码。

14B：$C=5120$，$n_{\mathrm{head}}=40$，$d=128$。

## 1. 原始输入（图 2(a) 左边四路）

1. **视频 / 噪声潜变量**
   - 像素首帧：`[3, 480, 832]`
   - 噪声潜变量：`[16, 21, 60, 104]`
   - I2V 条件 `y`：首帧可见性的 $4$ 通道 mask + 首帧 VAE，再与噪声在通道维拼接 → DiT 入口 `[36, 21, 60, 104]`
2. **文本**：T5 截断/填充到 $512$。
3. **两路音频** $\mathrm{Audio}_1,\mathrm{Audio}_2$：每人一条 wav，$16$ kHz。
4. **Mask List**：每人一张脸框。训练用整段视频脸框的**并集（最大框）**；推理用首帧 InsightFace 再略膨胀。像素上是两张 `[480, 832]` 的 $0/1$ 图。

首帧上还要裁出两张脸，后面给 CLIP 用。

## 2. 各编码器：进什么、出什么

### 2.1 3D VAE + patchify → Video Tokens $X$

```
噪声+条件              [36, 21, 60, 104]
Conv3d patch (1,2,2)    →  [5120, 21, 30, 52]
flatten 时空            →  [32760, 5120]
```

图里那一排橘色 Video Tokens，也是后面所有注意力的 Query。$32760=21$ 时间格 $\times 30$ 高 $\times 52$ 宽；$5120=$ DiT 隐维。

### 2.2 T5 → Text Tokens

```
文本 → T5     [512, 4096]     512=token, 4096=T5 宽
     → Linear [512, 5120]
```

### 2.3 CLIP：两处用法，不要混

同一套 CLIP ViT-H/14，输出都是 `[257, 1280]`（$256$ 个 $14\times 14$ patch + $1$ 个 CLS），再经 `MLPProj` 映到 DiT 维。

| 用法         | 输入                                                   | 输出                    | 图里叫什么                                   |
| ------------ | ------------------------------------------------------ | ----------------------- | -------------------------------------------- |
| 整张首帧     | `[3, 480, 832]`                                      | `[257, 5120]`         | **Ref Tokens**（Reference Cross-Attn） |
| 每人裁出的脸 | `[3, h_{\mathrm{face}}, w_{\mathrm{face}}]` × $2$ | 每人一份`[257, 5120]` | **Face token**（进 AFCA 的 KV）        |

`Ref Tokens` 管「整张图长什么样；`Face token` 管「这一路音频对应哪张脸。两套线性层。

### 2.4 Wav2Vec2 + AudioProj → Audio Tokens

对**每一路**音频单独做：

```
波形 16 kHz
→ Wav2Vec2 12 层隐状态，按 24 fps 抽到 81 帧
  [81, 12, 768]          81=像素帧, 12=层, 768=wav2vec 宽
→ 每帧再叠 ±2 邻帧窗
  [81, 5, 12, 768]       5=时间窗
→ AudioProj 展平再投影
  [81, 5*12*768] = [81, 46080]
  → Linear 512 → 512 → 32×5120
  [81, 32, 5120]          32=每帧 context token
→ 展平时间
  [2592, 5120]            2592=81×32
```

图里黄色 Audio tokens 实际是 $2592$ 个，不是两颗黄方块。

论文「每 $4$ 个音频 token 绑 $1$ 个视频 token里的 token 其实是**音频帧**。投影后每帧 $32$ 个 key，所以后面每个 VAE 格实际看见 $4\times 32=128$ 个音频 key。

### 2.5 Mask → Mask Tokens $M_{\mathrm{token}}$

每人一张：

```
像素脸框 [480, 832]
→ resize 到 patch 网格 [30, 52]
→ 沿 21 个时间格复制
  [21, 30, 52]
→ flatten
  [32760, 1]    与 Video Tokens 一一对应：1=这格属于这张脸
```

两人：`face_mask_list = [M^{(1)}, M^{(2)}]`，每份 `[32760, 1]`。推理路径：`expand_face_mask_flexible` → interpolate 到 `(lat_h//2, lat_w//2)` → `gen_inference_masks` 沿 latent 帧复制。

## 3. 一个 Attention Block 里四件事

隐状态 $X\in\mathbb{R}^{B\times 32760\times 5120}$ 过 $N$ 层，每层：

1. **Self-Attn**：视频 token 互看。
2. **Text Cross-Attn**：$Q=X$，$K,V=$ 文本 $512$ 个 token。
3. **Reference Cross-Attn**：$Q=X$，$K,V=$ 整图 CLIP $257$ 个 token。
4. **AFCA**：$Q=X$，对每一个人各做一次音–脸交叉注意力，再用这人的 mask 挡住，最后求和。

代码里 2/3/4 写在同一个 `WanAF2VCrossAttention` 里、共享一次输出投影 `self.o`，和论文画成四个框是一回事：都是加到 $X$ 上的残差。

论文式 (2) 写 $\mathrm{Concat}(f_{\mathrm{audio}},f_{\mathrm{face}})\cdot W_K$（先拼特征再投）。代码是脸、音频**分两套 Linear 后再沿序列维 cat**（脸在前）。功能等价于「视频 $Q$ 同时看见这张脸和这路声，梯度路径不同。对照以代码为准。

## 4. AFCA 逐步拆开（图 2(c)）

对第 $i$ 个人，输入三样：

| 名字        | 形状                    | 含义                                         |
| ----------- | ----------------------- | -------------------------------------------- |
| $Q$       | `[B, 32760, 40, 128]` | 全体视频 token，**所有人共用同一份 Q** |
| $K_i,V_i$ | 见下                    | 只含第$i$ 人的脸 + 第 $i$ 路音频         |
| $M_i$     | `[B, 32760, 1]`       | 第$i$ 人的空间门                           |

### 4.1 拼 KV（图里「两黄 + 一蓝）

```
Face_i  [B, 257, 5120]
→ W_K^face / W_V^face
  K_face [B, 257, 40, 128]     257=CLIP token
  V_face 同上

Audio_i [B, 2592, 5120]
→ W_K^audio / W_V^audio
  K_audio [B, 2592, 40, 128]   2592=81帧×32
  V_audio 同上

K_i = cat(K_face, K_audio, dim=1)   # [B, 2849, 40, 128]
V_i = cat(V_face, V_audio, dim=1)   # 前 257 是脸，后 2592 是音频
```

真长度是 **257 脸 + 2592 音频**。脸那一段注意力掩码全 `True`（身份不受时间窗限制）；音频那一段才跟 $M_{\mathrm{temporal}}$。

### 4.2 时间注意力掩码 $M_{\mathrm{temporal}}$（图 3(a)）

Query 轴是 $32760$ 个视频 token，时间规则只看「它属于哪一个 VAE 格：

- **第 $0$ 格**（对应 $1560$ 个空间 token）：看**全部 $81$ 帧音频**（$\times 32\to 2592$ 个 key 全开）。让开场吃到整句韵律/身份。
- **第 $t=1\ldots 20$ 格**：只看 $4$ 个音频帧。$t=1$ 看 `[1:5]`，$t=2$ 看 `[5:9]`……正好 $20\times 4=80$，第 $0$ 音频帧只给第一格。
- **脸那 $257$ 个 key：每一行全是 $1$**。

```
M_temporal  [B, 1, 32760, 2592]    只管音频段
拼上脸段全 True 后
attn_mask   [B, 1, 32760, 2849]    前 257 全 1，后 2592 按上表
```

交叉注意力（时间门必须在 softmax **之前** 做成 $-\infty$，见 §5）：

```
Attn_i = softmax(Q K_i^T / √d  ⊙ attn_mask) V_i
       → [B, 32760, 40, 128]
       → flatten [B, 32760, 5120]
```

到这一步，**整幅画面每个格子都已经看过第 $i$ 路声和第 $i$ 张脸**。不加空间门，左边的人也会跟着右边的音频动嘴。

### 4.3 空间门 $M_{\mathrm{token}}$（图 3(b)）

```
AFCA_out^(i) = Attn_i ⊙ M_i
# [B, 32760, 5120] ⊙ [B, 32760, 1]
# 落在第 i 张脸框里的格子保留这路音–脸残差，框外清零
```

### 4.4 对人循环，再求和

同一套 $W_K,W_V$，不复制层：

```
output = 0
for i in [人1, 人2, …]:
    q = W_Q(X)                              # 共用
    k, v = proj(concat(Face_i, Audio_i))
    attn_i = CrossAttn(q, k, v, M_temporal)
    output = output + attn_i * Mask_i
H ← H + output
```

两人时 $H'=H+\mathrm{AFCA}_{\mathrm{out}}^{(1)}+\mathrm{AFCA}_{\mathrm{out}}^{(2)}$，三份都是 `[B, 32760, 5120]`。人变成 $3$、$4$ 个只是 for-loop 多转几圈。这是「可任意缩放 ID在实现上的全部含义——绑定不在循环里，在 $M_{\mathrm{token}}$ 里。

## 5. 空间门为什么乘在 `Attn_i` 上，而不是乘进 softmax

两条门卡的是注意力矩阵的 **不同轴**：

|                | 时间掩码$M_{\mathrm{temporal}}$                                   | 空间门$M_{\mathrm{token}}$                       |
| -------------- | ------------------------------------------------------------------- | -------------------------------------------------- |
| 卡的是         | **Key**：这一格此刻该读哪几帧音频                             | **Query**：读完之后残差写到哪些格子          |
| 和另一维的关系 | 随$(t_{\mathrm{video}}, t_{\mathrm{audio}})$ 变，同一空间位置共用 | 随$(h,w)$ 变，对所有 key 相同                    |
| 若不进 softmax | 窗外的 key 仍占概率质量，口型被整句音频稀释                         | 框外本来就不该**写入**，不需要改框内的归一化 |

### 5.1 乘在输出上 $\Leftrightarrow$ 乘在该行 softmax 权重上

交叉注意力一行对应一个视频格子：

\[
\mathrm{Attn}_i[q]=\sum_k A_i[q,k]\,V_i[k],\quad
A_i[q,:]=\mathrm{softmax}(\text{第 }q\text{ 行分数})
\]

空间门只看 query 下标 $q$（这个格子在不在第 $i$ 张脸上）：

\[
\bigl(\mathrm{Attn}_i \odot M_i\bigr)[q]
= M_i[q]\sum_k A_i[q,k]\,V_i[k]
= \sum_k \bigl(A_i[q,k]\cdot M_i[q]\bigr)\,V_i[k]
\]

对注意力输出乘 $M_i$，等于对 softmax **之后**的整行权重乘同一个 $M_i[q]$，再去乘 $V$。框内（$M=1$）一行原封不动；框外（$M=0$）整行变成 $0$。

softmax 是 **按行** 做的。掐掉框外那些行，**不会**改变框内行的 $A_i[q,:]$。因此「只让脸框里的 $Q$ 去看这路声和「所有 $Q$ 都看完再把框外输出清零，对框内口型来说数值一样。

### 5.2 时间门必须进 softmax；空间门放输出才干净

时间约束是「允许的 key 集合，必须在 softmax **之前**做成 $-\infty$，剩下的 $4$ 帧音频（$\times 32$）才会重新归一化成和为 $1$。若先对全体音频做完 softmax，再把窗外权重乘 $0$，框内格子读到的是被挖空的分布，和不再是 $1$，口型会对糊。

空间约束是「允许的**写**位置。框内那一行该看哪些音频，时间掩码已经定完；再乘 $M_i$ 只是不让这笔残差落到别人脸上。

若把空间门也做成「分数 $\odot M_i$且只是乘 $0$、**不当成 $-\infty$**：

- 框外一行分数全 $0$ → softmax 变成**均匀分布** → 输出是 $V$ 的均值（整路音频+脸的平均特征）
- 若不把输出再乘 $0$，背景会被灌进一路平均人声

输出相乘是空间门最干净的写法。若坚持做进 `attn_mask`，正确姿势是：框外整行 $-\infty$，并且规定这些 query 的输出为 $0$——和 $\mathrm{Attn}_i\odot M_i$ 又回到同一件事，只是多占一块 `[32760, 2849]` 的掩码。时间掩码已经是 `[B, 1, 32760, 2592]`；空间门只是 `[32760, 1]` 的逐元素乘。

梯度：$\partial L/\partial\mathrm{Attn}_i = (\partial L/\partial\mathrm{Out})\odot M_i$，框外 query 这一路 CA 没有梯度；$W_Q$ 的梯度只从框内格子（外加文本/参考 CA）过来。

## 6. 「干脆做成动态时空掩码为什么不是同一架构

**对单独一次第 $i$ 人的 CA**，把空间折进注意力掩码

\[
\texttt{attn\_mask}[q,k]=M_{\mathrm{temporal}}[q,k]\;\wedge\;(M_i[q]=1)
\]

再规定框外输出为 $0$，与输出门等价。AnyTalker 没这么写，主要是实现：时间规则所有人共用，空间规则每人一张。

**所有人拼成一次 CA、用一张时空掩码做路由**则不再等价：

```
KV = [Face1, Audio1, Face2, Audio2, …]
左框格子只看人1，右框只看人2，重叠看两路，背景谁都不看
```

|                        | AFCA（循环 + 输出门 + 求和）                   | 一次 CA + 联合时空掩码                  |
| ---------------------- | ---------------------------------------------- | --------------------------------------- |
| 每人 softmax           | 独立，只在自己的 KV 上归一化                   | 多人 KV 抢同一行 softmax，权重和为$1$ |
| 两框重叠（凑近、肩膀） | 两路残差**相加**，两路声都灌进同一批格子 | 两路**竞争**注意力质量            |
| 背景                   | 两路都$\times 0$                             | 不看任何音频 key                        |
| 人数变多               | for-loop，参数不变                             | 掩码表要按人数重排，或预留槽位          |

AFCA 的目标是「同一套参数、对人循环、残差盖上去，不是「在一次注意力里学谁看哪路声。联合时空掩码更接近 MultiTalk 的 L-RoPE / Bind 的 $\mathbf{A}^{\mathrm{av}}$：绑定发生在注意力支撑集里，而不是写残差之后。

另外，$M_{\mathrm{token}}$ 也**不是**按帧跟踪的动态框。训练是整段视频脸框并集；推理是首帧检测再膨胀，再沿 $21$ 个时间格**复制同一张**。作者用最大框，是怕单帧小框在晃头后面被 flatten 对错格子；换位、走动的视频在数据管线里直接扔掉。真做成「每帧不同的时空掩码才能绑走动/换边，但那是另一套方法和另一套数据，不是把 $M_i$ 从输出挪到 softmax 就能得到的。

## 7. 一步 DiT 里 AFCA 看到的东西（收表）

```
X / Q          [B, 32760, 5120]     全体视频格子
Text           [B, 512, 5120]       文本 CA 用，AFCA 不用
Ref            [B, 257, 5120]       整图 CLIP，Reference CA 用
Audio_1/2      [B, 2592, 5120]      各人的声
Face_1/2       [B, 257, 5120]       各人的脸 CLIP
M_1, M_2       [B, 32760, 1]        各人的空间门

AFCA 第 i 次：
  KV_i         [B, 2849, 5120]      257 脸 + 2592 音频
  时间掩码      [B, 1, 32760, 2849]
  Attn_i       [B, 32760, 5120]     全图都看过这一路
  × M_i        [B, 32760, 5120]     只留在第 i 张脸上
求和后残差      [B, 32760, 5120]     加回 X
```

画面语言：把 $32760$ 个 token 想成切成格子的两人合影（再叠 $21$ 个时间层）。算人 $1$：每个格子都去读「人 $1$ 的脸 + 人 $1$ 当前音素（第一格读整句）；乘人 $1$ 的白框，只留左脸。人 $2$ 同理留右框。两块残差加回去。

图上容易误导的两处：

- **两黄一蓝**：示意「声 + 脸，不是 $3$ 个 token。
- **图 3 竖着 $F+1$ 个粉格**：每个时间格的 $30\times 52$ 个空间 token 被画成了一颗。
